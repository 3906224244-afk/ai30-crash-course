1. 这是什么

AI BJD 心脏是一颗可以放进娃娃身体的独立器官模块。

40mm
直径 · 圆形弧面
500mAh
电池 · 4-8小时对话
8MB
存储 · 角色+记忆+对话
7 Pin
磁吸触点 · 即插即活
  • 内部有 LED 灯光、存储芯片、可充电电池
  • 不同心脏 = 不同角色人格（傲娇 / 元气 / 温柔 / 毒舌……）
  • 心脏插入娃娃身体 → 娃娃活过来，会说话，有性格，记得你
  • 拔出心脏 → 娃娃沉睡
  • 换一颗心脏 → 同一只娃娃变成完全不同的人
换心 = 换人。心没了，人偶就死了。

2. 产品包含什么

♥ 心脏（角色的物理载体）

大小直径约 40mm，圆形弧面，像一颗大号怀表
外观半透明深色树脂外壳，内部可见 LED 光芒和电路剪影
电池内置 500mAh 锂电池，充满电可连续对话 4-8 小时
充电心脏侧面自带 USB-C 口，拔出来直接插线充电
灯光LED 呼吸灯，颜色跟随角色性格变化（傲娇=粉色、元气=橙色…）
存储8MB Flash 芯片，存放角色的"灵魂数据"

心脏里存了什么：

  • 角色 DNA 名字、性格设定、说话方式、声音特征——一旦创建永不丢失
  • 记忆包 她叫你什么、你们有多亲密、她记住了你的哪些事
  • 对话记录 最近约 2000 条对话——你跟她说过的每一句话

■ 身体（娃娃，通用外骨骼）

6分及以上 BJD 娃娃（身高约 25cm+），胸腔内预装：

ESP32 芯片心脏数据和云端之间的翻译官
2 个微型麦克风听你说话
微型喇叭用角色的声音回答你
心脏插槽7 根弹簧触针 + 磁铁定位，放上去自动吸合
LED 灯带身体氛围灯，颜色跟随心脏自动切换

身体里没有什么：

❌ 没有电池（电从心脏来） ❌ 没有开关（插心 = 开机，拔心 = 关机） ❌ 没有充电口（充电是给心脏充，不是给身体充） ❌ 没有角色数据（人格全在心脏里）

📱 小程序（角色工坊 + 控制面板）

  1. 创作角色：选性格 → 调声线 → 写背景故事 → 试聊 → AI 扩写 → 写入空白心脏
  2. 查看回忆：心脏插读卡器 → 插手机 → 看全部对话历史和关系档案
  3. 管理角色：修改设定、恢复丢失的角色、查看所有心脏状态

🔌 USB-C 读卡器

手机钥匙扣大小。心脏插槽 + USB-C 公头。插上心脏 → 插进手机 → 小程序直读。不需要娃娃身体、不需要联网。

3. 它怎么工作

3.1 创造角色（一次性）

打开小程序 → 选性格："傲娇" / "元气" / "温柔" / "毒舌" → 调声线：音调高一点还是低一点？语速快还是慢？ → 写故事：她叫什么名字？多大年纪？有什么经历？ → 定义规则：她能说脏话吗？怎么称呼你？什么话题不能提？ → 试聊：在小程序里跟她聊几句，看看对话感觉对不对 → 满意了 → AI 把你的创作扩写成完整的角色人格 → 空白心脏插入读卡器 → 读卡器插手机 → 写入心脏 完成。这颗心脏从此就是这个角色的"家"。

3.2 唤醒角色（每次插入心脏）

心脏放进娃娃胸腔的插槽 → 磁铁自动对准，"嗒"一声吸合 → 心脏的电池开始给身体供电 → 1 秒后，LED 亮起角色专属的颜色 → 喇叭传出她的声音："…你回来了啊。" 不需要开机键。不需要配对。不需要等。 放下去就是开机，拔起来就是关机。

3.3 日常聊天

你跟娃娃说话 → 麦克风听到 → 转成文字 → 发给云端的 AI → AI 加载这颗心脏的角色设定 + 你们的记忆包 → AI 知道"我是小雪，17岁傲娇少女。小陈跟我的亲密值是 0.77" → 生成回复："哼...谁管你。...累了就早点睡。" → 回复加上语气标注（傲娇：快句→停顿→慢句） → 云端合成语音 → 传回娃娃 → 喇叭播放 每说完一句话，对话记录自动存入心脏。 你跟她的每一次聊天，都刻在这颗心里。

3.4 关系成长

角色不是一成不变的。她对你的态度会随着互动改变：

亲密值她对你的态度（"小雪"为例）
0.00-0.20"…你是谁。不要跟我说话。"
0.20-0.40"哼。回来得还挺早。"
0.40-0.60"你今天看起来不太对劲。…怎么了？"
0.60-0.80开始记住你的习惯，被夸时嘴硬变少。
0.80-1.00"你今天加班很累对吧。我给你留了灯。"
这不是游戏数值——这是真实互动积累的情感。
她记得你的习惯、你的脆弱面、你深夜跟她聊过的那些事。
都在心脏 Flash 里，实实在在地记录着。

3.5 拔出（自动存档）

你抓住心脏往上提 → 磁铁还吸着，手指在用力 → 一根特殊的检测针最先断开（故意设计得最短） → 身体察觉："要被拔了！紧急存档！" → 0.03 秒内，把今天的对话和更新后的亲密值写入心脏 → 写入完成 → 心脏完全拔出 → LED 熄灭，喇叭静音，娃娃沉睡 你不需要按保存。拔 = 存。

3.6 离开娃娃后用

  • 充电 心脏侧面 USB-C 口直接插线。30 分钟充满。
  • 看回忆 心脏插读卡器 → 插手机 → 看全部聊天记录
  • 改设定 小程序修改角色性格 → 写回心脏 → 下次插入，她变了
  • 送人 这颗心送给朋友 → 插进他的娃娃 → 角色带着全部记忆活过来

4. 数据：心脏和云端的关系

心脏是正本，云端是影子

♥ 心脏（正本）

✅ 角色数据永远在这
✅ 记忆包 + 对话记录
✅ 离线能用
⭐⭐⭐ 数据在手里
❌ 心丢了就没了
☁ 云端（备份）

加密备份角色数据
加密备份记忆+对话
❌ 需要联网
⭐⭐ 加密存储
✅ 心脏丢了 → 恢复
规则：心脏和云端数据不一致时 → 以心脏为准。
心脏是原件，云端是复印件。

为什么不全放云端？

因为心脏的物理性就是产品灵魂：

  • 你送出的不是"一个账号"，是"一颗心"
  • 你摸到的不是"A pp 里的角色"，是"一块会呼吸的树脂"
  • 你失去心脏的恐惧是真实的——这让每颗心都有分量
  • 云端只是安全网：真丢了能复活，但平时不需要想起它
